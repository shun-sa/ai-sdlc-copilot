# ADR-012 フロントエンドをサーバーサイドレンダリングで構成する

## Status

Accepted

## Related Requirements

- FR-003
- NFR-SEC-005

## Context

一覧・詳細・カート・注文・履歴等の画面提供が必要で（FR-003ほか）、
出力時のXSS防止（NFR-SEC-005）を確実にする描画方式を確定する必要がある。
詳細画面イメージはPLAN工程で作成される前提である。

## Decision

サーバーサイドレンダリング（自動エスケープ有効なテンプレートエンジン）を採用する。
動的部分は必要最小限のプログレッシブ拡張に留める。

## Alternatives

- サーバーサイドレンダリング（採用）
  - 自動エスケープでXSSを構造的に抑止し要件規模に適合
- SPA（React等）＋API分離（不採用）
  - 本要件規模に対し構成が重く初期コストが高い
- 手組みHTML文字列生成（不採用）
  - エスケープ漏れが生じやすくNFR-SEC-005に不適

## Consequences

- メリット: 出力エスケープを標準化でき実装がシンプル
- デメリット: 高度なクライアント操作性には追加実装が必要
- 後続工程: 画面はSSR前提でPLAN/実装・テストを進める

## AI Guardrails

- テンプレートの自動エスケープを無効化して出力してはならない（NFR-SEC-005）
- 未検証のユーザー入力をHTMLへ直接埋め込んではならない
