# ADR-006 認可（本人リソース所有チェック）

## Status

Accepted

## Related Requirements

- NFR-SEC-003
- FR-010
- C-AUTH-004

## Context

会員は自身のカート・注文・チケット・購入履歴のみ参照できる
（C-AUTH-004, NFR-SEC-003）。履歴確認（FR-010）等で他人データ露出は不可。

## Decision

各リソースアクセスでセッションのユーザーIDと対象リソースのuser_idを
サーバー側で照合し、不一致は拒否する（水平権限昇格を防止）。
一覧・取得クエリは常に本人user_idで絞り込む。

## Alternatives

- 画面非表示のみで制御
  - 不採用: 直接IDアクセスで他人データを取得可能
- IDの推測困難性に依存
  - 不採用: 推測/総当たりで突破可能、SEC-003違反
- サーバー側所有チェック＋本人絞り込み
  - 採用: 直接アクセスでも他人データを返さない

## Consequences

- メリット: 水平権限昇格を防ぎ他会員データ露出を防止
- デメリット: 全データアクセス経路で所有検証が必要
- 後続工程: 取得系は必ず本人user_idで絞り込みまたは所有検証する

## AI Guardrails

- 対象リソースのuser_id所有検証を省略してはならない
- クライアント提供のuser_idを検証なしに信頼してはならない
