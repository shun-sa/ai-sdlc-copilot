# ADR-004 パスワードハッシュ方式

## Status

Accepted

## Related Requirements

- NFR-SEC-001
- FR-001

## Context

会員登録（FR-001）でパスワードを保存し、NFR-SEC-001はハッシュ化保存を要求する。
平文・可逆暗号・高速ハッシュはオフライン総当たりに弱い。

## Decision

パスワードはbcryptで一方向ハッシュ化して保存する（DM-001 password_hash）。
平文・可逆暗号・生MD5/SHA等の高速ハッシュは使用しない。

## Alternatives

- 平文/可逆暗号
  - 不採用: NFR-SEC-001違反で漏洩時に即時悪用される
- SHA-256単純ハッシュ
  - 不採用: ソルト/ストレッチ不足で総当たりに弱い
- bcrypt
  - 採用: ソルト内蔵・コスト調整可能で標準的に安全

## Consequences

- メリット: ソルト内蔵で総当たり耐性が高く実装が標準化される
- デメリット: 検証コストが高く認証応答が僅かに遅くなる
- 後続工程: 認証はハッシュ照合のみ、平文パスワードを保存/ログ出力しない

## AI Guardrails

- パスワードを平文・可逆暗号・高速ハッシュで保存してはならない
- パスワードやハッシュをログ・レスポンスへ出力してはならない
