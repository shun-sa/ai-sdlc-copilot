## 1. 本書の目的と適用範囲



### 1.1 目的

本書は、MiniCommerce に関わる利用者・外部システムの目的と、システム利用の単位をUser Story / Use Caseとして一覧化し、Requirementおよび個別ユースケース定義との対応を明確にすることを目的とする。
