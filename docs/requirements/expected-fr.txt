# 対象外機能（functional_requirements.md 2.3 対象外機能 FR-OUT-01〜16。理由と代替手段・担当は同表の記載）
EXCLUDE FR-OUT-01: 対象外機能「実決済サービスとの連携」。理由: 決済代行事業者が未選定。代替手段・担当: 模擬決済（決済サービス（模擬））で代替する。後続フェーズで検討する
EXCLUDE FR-OUT-02: 対象外機能「商品・商品分類・仕入先・在庫単位・クーポンの画面／Web API による登録・更新・削除（マスタ保守）」。理由: 初期商品数が限られ、改廃頻度が低い。代替手段・担当: 運用者が初期データ一括投入（FR-060）で登録・再投入する
EXCLUDE FR-OUT-03: 対象外機能「入荷・在庫補充の登録」。理由: 現行の在庫管理表で運用を継続する。代替手段・担当: 稼働開始時の在庫数量は初期データ一括投入（FR-060）で登録する。稼働後の補充分の反映方法は FOQ-01 で決定する（本リリースは登録済みの在庫数量を補充する機能を持たない）
EXCLUDE FR-OUT-04: 対象外機能「返品・返金・部分出荷・分割配送」。理由: 件数が少ない。代替手段・担当: 支払済注文のキャンセル時の返金は、EC運営担当が本システム外で手作業で対応する
EXCLUDE FR-OUT-05: 対象外機能「複数クーポンの併用、ポイント、ギフト券、自動適用の割引キャンペーン」。理由: 割引は単一クーポンに限定する。代替手段・担当: 実施しない
EXCLUDE FR-OUT-06: 対象外機能「多通貨・多言語・海外配送・多国税制」。理由: 国内向け販売のみ。代替手段・担当: 実施しない（日本語・日本円・国内のみ）
EXCLUDE FR-OUT-07: 対象外機能「配送業者との連携、住所検証、配送日時指定、送料の地域別設定」。理由: 出荷は運営側の手作業で行う。代替手段・担当: 管理者が出荷登録（FR-043）・配達完了登録（FR-044）を行う
EXCLUDE FR-OUT-08: 対象外機能「メールその他の手段による利用者への通知（注文確認メールを含む）」。理由: 初期リリースでは画面・Web API での状態確認で代替する。代替手段・担当: 実施しない
EXCLUDE FR-OUT-09: 対象外機能「会員情報の変更、パスワード再設定、退会」。理由: 初期リリースの範囲を限定する。代替手段・担当: EC運営担当が問い合わせを受けて個別に対応する（本システム外）
EXCLUDE FR-OUT-10: 対象外機能「未ログイン状態でのカート利用（ゲスト購入）」。理由: 会員向けサービスとして開始する。代替手段・担当: カート・注文はログインを必須とする
EXCLUDE FR-OUT-11: 対象外機能「認証失敗時のアカウントロック、ログイン試行回数の制限」。理由: 初期リリースの範囲を限定する。代替手段・担当: 実施しない（後続フェーズで検討する）
EXCLUDE FR-OUT-12: 対象外機能「未払い注文の自動キャンセル（期限切れ処理）」。理由: 初期リリースの範囲を限定する。代替手段・担当: 購入者（FR-034）または管理者（FR-045）がキャンセルする
EXCLUDE FR-OUT-13: 対象外機能「商品画像、商品レビュー、お気に入り、おすすめ表示」。理由: 初期リリースの範囲を限定する。代替手段・担当: 実施しない
EXCLUDE FR-OUT-14: 対象外機能「スマートフォン専用画面」。理由: 初期リリースはPCブラウザを対象とする。代替手段・担当: 後続フェーズで検討する
EXCLUDE FR-OUT-15: 対象外機能「帳票（PDF・CSVを含むファイル出力）」。理由: 一覧画面での確認で足りる。代替手段・担当: 実施しない
EXCLUDE FR-OUT-16: 対象外機能「「特定商取引法に基づく表記」を含む静的ページ」。理由: サイト運営側の静的コンテンツとして別途用意する。代替手段・担当: 本システムの対象外
