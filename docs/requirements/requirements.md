## 1. 用語集

| 用語 | 定義 |
| --- | --- |
| ゲストユーザー | 未ログインの利用者。映画/商品の閲覧、会員登録、ログインが可能。 |
| 会員ユーザー | ログイン済みの利用者。注文、チケット購入、購入履歴確認が可能。 |
| 商品注文 | 物販商品の購入処理。カートを経由して確定する。 |
| チケット購入 | 上映回を選択して映画チケットを購入する処理。 |
| 購入履歴 | 商品注文履歴とチケット購入履歴の総称。 |
| 販売期間外 | 商品または上映回が購入対象期間外の状態。 |

## 2. 背景

映画作品の閲覧から映画関連商品の購入、映画チケット購入までを一貫して提供する顧客向けWebシステムが必要である。現状は機能が分散し、ユーザー体験と業務データ管理の一貫性が不足している。

## 3. 目的

一般ユーザーおよび会員ユーザーが、映画作品を検索・閲覧し、映画関連商品や映画チケットをオンラインで購入できるようにする。

## 4. 誰のために

- ゲストユーザー: 映画・商品の閲覧、会員登録、ログインをしたいユーザー
- 会員ユーザー: 商品購入、チケット購入、購入履歴確認をしたいユーザー

## 5. 開発のスコープ外（Out of Scope）

- OOS-001: 外部決済サービスとの本番連携
- OOS-002: 座席指定チケット販売
- OOS-003: 電子チケットQRコード発行
- OOS-004: 商品レビュー・評価機能
- OOS-005: ポイント付与・利用
- OOS-006: クーポン配布
- OOS-007: AIレコメンド
- OOS-008: メール送信基盤との実連携
- OOS-009: 配送会社API連携
- OOS-010: 多言語・多通貨対応

## 6. 成功条件（Acceptance Criteria）

- AC-COM-001: 未登録ユーザーが会員登録を完了できる（正常系テストで成功率100%）
- AC-COM-002: 登録済みユーザーがログインできる（正常系テストで成功率100%）
- AC-COM-003: 会員ユーザーが商品を検索し、カート追加から注文確定まで完了できる（主要シナリオ3件で成功率100%）
- AC-COM-004: 会員ユーザーが映画チケットを購入できる（主要シナリオ3件で成功率100%）
- AC-COM-005: 会員ユーザーが自分の購入履歴を確認できる（商品注文1件以上、チケット購入1件以上が表示される）
- AC-COM-006: 入力不備・在庫不足・権限不足・認証失敗・販売期間外の5分類で、定義済みエラー表示と遷移先が一致する（分類ごとに異常系テスト1件以上、合格率100%）

## 7. 業務フロー/ユーザーストーリー

- As a ゲストユーザー
- I want 映画作品と商品を検索し、必要に応じて会員登録/ログインしたい
- So that 映画関連商品とチケットをスムーズに購入できる

- As a 会員ユーザー
- I want カート編集、注文確定、チケット購入、履歴確認を行いたい
- So that 購入体験を一つのサービス内で完結できる

## 8. 共通機能要件

- C-UI-001: 各画面にヘッダー、検索導線、ログイン状態表示、カート導線を表示する
- C-UI-002: 入力エラー時、該当項目近傍にエラーメッセージを表示する
- C-UI-003: 一覧画面に検索条件、結果件数、ページングを表示する
- C-UI-004: 金額は税込・3桁区切り円表記で表示する（例: 1,980円）
- C-UI-005: 日時は YYYY/MM/DD HH:mm 形式で表示する
- C-DATA-001: 削除済み/非公開の商品・映画作品は顧客向け画面に表示しない
- C-DATA-002: 販売開始前/販売終了後の商品は閲覧可能でも購入不可とする
- C-DATA-003: 在庫0の商品は購入不可かつ「在庫なし」と表示する
- C-DATA-004: 注文確定時点の価格・商品名・数量・割引情報を保持する

## 9. 認証・認可

- C-AUTH-001: ゲストは映画検索、映画詳細閲覧、商品検索、商品詳細閲覧、会員登録、ログインを利用できる
- C-AUTH-002: 会員は上記に加えてカート、注文、チケット購入、購入履歴確認を利用できる
- C-AUTH-003: ログイン必須機能へ未ログインでアクセスした場合はログイン画面へ遷移する
- C-AUTH-004: 会員は自分自身のカート、注文、チケット、購入履歴のみ参照できる

## 10. エラー仕様（共通）

- ERR-001: 必須入力不足・形式不正時は項目単位でエラーメッセージを表示
- ERR-002: 認証失敗時はメールアドレス存在有無を推測できる文言を表示しない
- ERR-003: 在庫不足時は注文/購入/カート追加を失敗させ、理由を表示
- ERR-004: 販売期間外、非公開、権限不足時は操作不可とし適切に遷移または通知
- ERR-005: 注文/チケット購入の更新失敗時は不整合データを残さない

## 11. 非機能要件（NFR）

- NFR-PERF-001: 映画検索、商品検索、購入履歴一覧は通常時3秒以内に初期表示
- NFR-PERF-002: カート追加、カート更新、注文確定、チケット購入確定は通常時5秒以内に応答
- NFR-PERF-003: 一覧画面はページングし、1ページ20件を標準とする
- NFR-SEC-001: パスワードはハッシュ化保存
- NFR-SEC-002: 要認証機能への未認証アクセスを許可しない
- NFR-SEC-003: 他会員データの参照・変更を禁止
- NFR-SEC-004: 入力値はサーバー側で検証
- NFR-SEC-005: SQLインジェクション、XSSを防止
- NFR-SEC-006: 認証失敗時にアカウント存在可否を推測可能にしない
- NFR-AVL-001: 注文登録と在庫減算の整合性を保つ
- NFR-AVL-002: チケット購入登録と残席減算の整合性を保つ
- NFR-AVL-003: 注文確定失敗時に不完全注文を残さない
- NFR-AVL-004: チケット購入失敗時に不完全購入を残さない
- NFR-USAB-001: トップ画面から主要機能へ遷移可能
- NFR-USAB-002: 入力エラー時に修正項目と理由を理解可能
- NFR-USAB-003: 注文確定前に配送先・支払・金額を確認可能
- NFR-USAB-004: チケット確定前に映画名・上映日時・券種・枚数・金額を確認可能

## 12. データモデル

- DM-001: User
  - id, name, email(unique), password_hash, created_at, status
- DM-002: Movie
  - id, title, synopsis, genre, release_date, runtime_minutes, status
- DM-003: Product
  - id, name, price_tax_included, stock, publish_status, sales_start_at, sales_end_at, movie_id(optional)
- DM-004: Cart / CartItem
  - cart_id, user_id
  - item_id, product_id, quantity
- DM-005: Order / OrderItem
  - order_id, order_number(unique), user_id, ordered_at, status, shipping_address, payment_method, total_amount
  - order_item_id, product_snapshot_name, unit_price, quantity, subtotal
- DM-006: Screening
  - screening_id, movie_id, starts_at, theater_name, screen_name, seats_remaining, sales_start_at, sales_end_at
- DM-007: TicketPurchase / TicketPurchaseItem
  - purchase_id, purchase_number(unique), user_id, purchased_at, total_amount
  - purchase_item_id, screening_id, ticket_type, unit_price, quantity

## 13. 機能要件（FR）

- FR-001: 会員登録
  - 機能目的
    - 購買機能利用のための会員アカウント作成
  - 機能概要
    - 氏名、メールアドレス、パスワード入力で会員登録を行う
  - ユーザーストーリー
    - ゲストとして、購入機能を使うために会員登録したい
  - 入力項目
    - 氏名（1-50文字）
    - メールアドレス（形式チェック / 255文字以内 / 一意）
    - パスワード（8-64文字、英数）
    - 確認用パスワード（パスワードと一致）
  - バリデーション
    - 必須入力、形式チェック、確認用パスワードとの一致、重複メール不可
  - データ構造（必要に応じて）
    - User（DM-001）を新規作成。パスワードはpassword_hashへハッシュ化保存（NFR-SEC-001）
  - 画面要件 ※詳細画面イメージは機能設計フェーズ（PLAN）でAIが作成
    - 会員登録画面。詳細画面イメージはPLANフェーズで作成
  - エラー条件
    - 既登録メール、形式不正、確認用パスワード不一致（ERR-001準拠）
  - 制約条件
    - 特になし（PJ全体制約に従う）
  - 非機能要件（任意, PJ全体非機能要件のカスタマイズ）
    - NFR-SEC-001, NFR-SEC-004
  - 出力/挙動・完了条件
    - 登録完了画面表示、必要に応じ自動ログイン

- FR-002: ログイン
  - 機能目的
    - 会員機能利用のための認証
  - 機能概要
    - メールアドレスとパスワードでログインする
  - ユーザーストーリー
    - 会員として、購入処理に進むためにログインしたい
  - 入力項目
    - メールアドレス
    - パスワード
  - バリデーション
    - 必須入力、形式チェック
  - データ構造（必要に応じて）
    - User（DM-001）を参照し認証する
  - 画面要件 ※詳細画面イメージは機能設計フェーズ（PLAN）でAIが作成
    - ログイン画面。詳細画面イメージはPLANフェーズで作成
  - エラー条件
    - 認証失敗時は汎用メッセージを表示（ERR-002 / NFR-SEC-006準拠。アカウント存在可否を推測させない）
  - 制約条件
    - 特になし（PJ全体制約に従う）
  - 非機能要件（任意, PJ全体非機能要件のカスタマイズ）
    - NFR-SEC-002, NFR-SEC-006
  - 出力/挙動・完了条件
    - ログイン状態となりトップまたは遷移元に戻る

- FR-003: 映画作品検索
  - 機能目的
    - 関心映画を探索する
  - 機能概要
    - タイトル・ジャンル・公開状況で検索、並び替え可能
  - ユーザーストーリー
    - ユーザーとして、見たい映画を素早く見つけたい
  - 入力項目
    - タイトルキーワード
    - ジャンル
    - 公開状況
    - 並び順
  - バリデーション
    - 任意入力、公開対象のみ表示（C-DATA-001準拠）
  - データ構造（必要に応じて）
    - Movie（DM-002）を検索対象とする
  - 画面要件 ※詳細画面イメージは機能設計フェーズ（PLAN）でAIが作成
    - 映画一覧画面。検索条件・結果件数・ページングを表示（C-UI-003）。詳細画面イメージはPLANフェーズで作成
  - エラー条件
    - 0件時は0件メッセージ表示
  - 制約条件
    - 特になし（PJ全体制約に従う）
  - 非機能要件（任意, PJ全体非機能要件のカスタマイズ）
    - NFR-PERF-001, NFR-PERF-003
  - 出力/挙動・完了条件
    - 一覧表示から詳細画面へ遷移可能

- FR-004: 映画作品詳細閲覧
  - 機能目的
    - 作品情報と購買導線の確認
  - 機能概要
    - 映画詳細、関連商品、上映スケジュールを表示
  - ユーザーストーリー
    - ユーザーとして、作品情報を確認して購入判断したい
  - 入力項目
    - 表示項目: タイトル、あらすじ、ジャンル、公開日、上映時間、関連商品、上映回（本機能はユーザー入力を伴わない表示機能）
  - バリデーション
    - 非公開作品は表示しない（C-DATA-001準拠）
  - データ構造（必要に応じて）
    - Movie（DM-002）、関連Product（DM-003）、Screening（DM-006）を参照
  - 画面要件 ※詳細画面イメージは機能設計フェーズ（PLAN）でAIが作成
    - 映画詳細画面。詳細画面イメージはPLANフェーズで作成
  - エラー条件
    - 特になし（表示対象が存在しない場合はC-DATA-001に従う）
  - 制約条件
    - 上映終了回は購入導線を表示しない
  - 非機能要件（任意, PJ全体非機能要件のカスタマイズ）
    - NFR-USAB-001
  - 出力/挙動・完了条件
    - 商品詳細遷移、会員はチケット購入導線利用可

- FR-005: 商品検索・閲覧
  - 機能目的
    - 商品発見と購入判断
  - 機能概要
    - キーワード/カテゴリ/関連映画で検索し、商品詳細を表示
  - ユーザーストーリー
    - ユーザーとして、欲しい映画関連商品を見つけたい
  - 入力項目
    - 商品名キーワード
    - カテゴリ
    - 関連映画
    - 在庫ありのみ（絞り込み）
  - バリデーション
    - 非公開/販売期間外/在庫なし制御（C-DATA-001, C-DATA-002, C-DATA-003準拠）
  - データ構造（必要に応じて）
    - Product（DM-003）を検索対象とする
  - 画面要件 ※詳細画面イメージは機能設計フェーズ（PLAN）でAIが作成
    - 商品一覧・商品詳細画面。検索条件・結果件数・ページングを表示（C-UI-003）。詳細画面イメージはPLANフェーズで作成
  - エラー条件
    - 0件時は0件メッセージ表示（C-UI-003に準ずる）
  - 制約条件
    - 特になし（PJ全体制約に従う）
  - 非機能要件（任意, PJ全体非機能要件のカスタマイズ）
    - NFR-PERF-001, NFR-PERF-003
  - 出力/挙動・完了条件
    - 会員はカート追加へ進める

- FR-006: 商品をカートに追加
  - 機能目的
    - 商品購入候補を保持
  - 機能概要
    - 商品詳細から数量指定でカート追加、同一商品は数量加算
  - ユーザーストーリー
    - 会員として、複数商品をまとめて購入準備したい
  - 入力項目
    - 数量（1以上、在庫以下）
  - バリデーション
    - 販売可否、在庫超過、ログイン状態（C-AUTH-002, C-DATA-002, C-DATA-003準拠）
  - データ構造（必要に応じて）
    - Cart / CartItem（DM-004）へ登録。カート投入時は在庫（Product.stock）を減算しない
  - 画面要件 ※詳細画面イメージは機能設計フェーズ（PLAN）でAIが作成
    - 商品詳細画面上のカート追加操作。詳細画面イメージはPLANフェーズで作成
  - エラー条件
    - 在庫超過、販売期間外、非公開時はカート追加を失敗させ理由を表示（ERR-003, ERR-004準拠）
  - 制約条件
    - カート投入時は在庫減算しない、注文確定時に減算（業務ルール）
  - 非機能要件（任意, PJ全体非機能要件のカスタマイズ）
    - NFR-PERF-002
  - 出力/挙動・完了条件
    - 追加完了表示、ヘッダーのカート件数更新

- FR-007: カート内容変更
  - 機能目的
    - 注文前の内容調整
  - 機能概要
    - 数量変更、削除、合計再計算、注文導線表示
  - ユーザーストーリー
    - 会員として、注文前に数量を調整したい
  - 入力項目
    - 数量（変更後の値。0は削除扱い）
  - バリデーション
    - 在庫超過不可、0は削除扱い
  - データ構造（必要に応じて）
    - Cart / CartItem（DM-004）を更新
  - 画面要件 ※詳細画面イメージは機能設計フェーズ（PLAN）でAIが作成
    - カート画面。詳細画面イメージはPLANフェーズで作成
  - エラー条件
    - 注文不可商品がある場合は注文手続き不可（ERR-003, ERR-004準拠）
  - 制約条件
    - 特になし（PJ全体制約に従う）
  - 非機能要件（任意, PJ全体非機能要件のカスタマイズ）
    - NFR-PERF-002, NFR-USAB-002
  - 出力/挙動・完了条件
    - 変更後の小計・合計が再計算される

- FR-008: 商品注文
  - 機能目的
    - 商品購入を確定
  - 機能概要
    - 配送先/支払方法入力、確認、注文確定、在庫減算、注文番号発行
  - ユーザーストーリー
    - 会員として、希望商品を配送先指定で注文確定したい
  - 入力項目
    - 氏名
    - 郵便番号
    - 都道府県
    - 市区町村・番地
    - 電話番号
    - 支払方法（提供する具体的選択肢はOQ-REQ-001として未確定）
  - バリデーション
    - 必須入力、形式チェック、最新在庫確認（ERR-001, ERR-003準拠）
  - データ構造（必要に応じて）
    - Order / OrderItem（DM-005）を作成。注文時スナップショット（商品名・単価・数量・小計）を保持（C-DATA-004）。注文確定時にProduct.stockを減算
  - 画面要件 ※詳細画面イメージは機能設計フェーズ（PLAN）でAIが作成
    - 注文入力・確認・完了画面。確定前に配送先・支払・金額を確認可能（NFR-USAB-003）。詳細画面イメージはPLANフェーズで作成
  - エラー条件
    - 在庫不足時は注文を失敗させ理由を表示（ERR-003）。更新失敗時は不整合データを残さない（ERR-005, NFR-AVL-001, NFR-AVL-003）
  - 制約条件
    - 決済は常に成功する模擬決済として扱う（CON-002）。外部決済サービスとの実連携は行わない（CON-001, OOS-001）
  - 非機能要件（任意, PJ全体非機能要件のカスタマイズ）
    - NFR-PERF-002, NFR-AVL-001, NFR-AVL-003, NFR-USAB-003
  - 出力/挙動・完了条件
    - 注文完了画面と注文番号表示、カートクリア

- FR-009: 映画チケット購入
  - 機能目的
    - 上映回の座席枠確保と購入確定
  - 機能概要
    - 上映回、券種、枚数選択で購入確定し、残席減算と購入番号発行
  - ユーザーストーリー
    - 会員として、希望上映回のチケットを購入したい
  - 入力項目
    - 上映回
    - 券種（初期ラインナップと価格ルールはOQ-REQ-002として未確定）
    - 枚数
    - 支払方法（模擬）
  - バリデーション
    - 販売期間、上映開始前、残席数（ERR-003, ERR-004準拠）
  - データ構造（必要に応じて）
    - TicketPurchase / TicketPurchaseItem（DM-007）を作成。Screening.seats_remaining（DM-006）を減算
  - 画面要件 ※詳細画面イメージは機能設計フェーズ（PLAN）でAIが作成
    - チケット購入入力・確認・完了画面。確定前に映画名・上映日時・券種・枚数・金額を確認可能（NFR-USAB-004）。詳細画面イメージはPLANフェーズで作成
  - エラー条件
    - 残席不足時は購入を失敗させ理由を表示（ERR-003）。更新失敗時は不整合データを残さない（ERR-005, NFR-AVL-002, NFR-AVL-004）
  - 制約条件
    - 座席指定は対象外（残席数管理のみ）（CON-004, OOS-002）。決済は模擬決済（CON-002）
  - 非機能要件（任意, PJ全体非機能要件のカスタマイズ）
    - NFR-PERF-002, NFR-AVL-002, NFR-AVL-004, NFR-USAB-004
  - 出力/挙動・完了条件
    - 購入完了画面表示、購入履歴に反映

- FR-010: 購入履歴確認
  - 機能目的
    - 過去購入の確認
  - 機能概要
    - 商品注文履歴とチケット履歴を本人分のみ一覧/詳細表示
  - ユーザーストーリー
    - 会員として、過去の注文内容を確認したい
  - 入力項目
    - 表示条件（本機能はユーザー入力を伴わず、本人分の履歴を表示する）
  - バリデーション
    - 本人アクセス制御（C-AUTH-004, NFR-SEC-003準拠）
  - データ構造（必要に応じて）
    - Order / OrderItem（DM-005）、TicketPurchase / TicketPurchaseItem（DM-007）を本人分のみ参照。購入時点スナップショットを表示（保持期間・表示件数上限はOQ-REQ-003として未確定）
  - 画面要件 ※詳細画面イメージは機能設計フェーズ（PLAN）でAIが作成
    - 購入履歴一覧・詳細画面。詳細画面イメージはPLANフェーズで作成
  - エラー条件
    - 本人以外の履歴へのアクセスは操作不可とする（ERR-004準拠）
  - 制約条件
    - 特になし（PJ全体制約に従う）
  - 非機能要件（任意, PJ全体非機能要件のカスタマイズ）
    - NFR-PERF-001, NFR-SEC-003
  - 出力/挙動・完了条件
    - 注文日/購入日降順で履歴を確認可能
