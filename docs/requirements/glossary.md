## 1. 本書の目的と適用範囲



### 1.1 目的

本書は、MiniCommerce に関する業務・システム・技術上の用語と表記を統一し、関係者間の解釈差異を防止することを目的とする。


### 1.2 適用範囲

| 区分 | 内容 |
|---|---|
| 対象 | MiniCommerce の要件定義成果物で使用する用語 |
| 本書で定義する | 正式名称、定義、カテゴリ、許容表記・略語、非推奨表記、関連Requirement、根拠・Owner |
| 本書で定義しない | 一般辞書と同じ意味で使用する一般語 |
| 適用対象成果物 | 要件定義書一式（業務・機能・非機能・データ・画面・外部インターフェース要件、ユースケース定義） |
