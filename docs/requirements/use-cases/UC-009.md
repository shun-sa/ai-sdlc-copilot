## 1. 本書の目的と適用範囲



### 1.1 目的

購入者が、出荷前（注文受付・支払済）の自分の注文を自分で取り消し、引き当てられていた在庫数量が全明細分だけ1回だけ在庫へ戻ることで、他の購入者が購入できる状態にする。


### 1.2 適用範囲

| 区分 | 内容 |
|---|---|
| Use Case ID | UC-009 |
| 対象ユースケース | 注文をキャンセルする（購入者） |
| 対象リリース・範囲 | MiniCommerce 初期リリース |
| 本書で定義する | Goal、Actor、Trigger、Precondition、Flow、Postcondition、Business Rule、AC |
| 本書で定義しない | 実装方式、画面デザイン詳細、物理データ構造、API・ファイルの物理仕様 |

対象範囲：

- 注文詳細画面（SCR-010）の「キャンセルする」によるキャンセル（実行前に確認を求める。Web API による要求を含む。FR-034）
- 状態 注文受付→キャンセル済（ST-PO-03）・支払済→キャンセル済（ST-PO-04）の遷移、キャンセル日時の記録、全明細の在庫戻し、注文状態履歴（実行者の利用者区分 購入者）の記録
- キャンセルできない状態（出荷済／配達完了／キャンセル済）の拒否と、二重キャンセルの防止

対象外：

- 支払済注文の返金（EC運営担当が本システム外で5営業日以内に行う。FR-OUT-04）
- 管理者によるキャンセル（UC-012）
- 出荷後の返品（FR-OUT-04）、明細単位の部分キャンセル
- 未払い注文の自動キャンセル（FR-OUT-12）
- キャンセル完了の通知メール（FR-OUT-08）

## 3. 目的・開始条件



### 3.1 Goal

購入者が、出荷前（注文受付・支払済）の自分の注文を自分で取り消し、引き当てられていた在庫数量が全明細分だけ1回だけ在庫へ戻ることで、他の購入者が購入できる状態にする。


### 3.2 Trigger

購入者が出荷前の注文を取り消すと決め、注文詳細画面（SCR-010）で「キャンセルする」を操作する。Web API でキャンセルを要求した場合も同じ。


### 3.3 Precondition

| ID | 前提条件 | 満たさない場合の扱い |
|---|---|---|
| PRE-UC-009-001 | 購入者がログイン済みで、ログイン状態の有効期間内である。 | ログインしていない、またはログイン状態の有効期間が切れている場合は EX-01、管理者の場合は EX-02 へ |
| PRE-UC-009-002 | 対象の注文がログイン中の購入者の注文として存在する。 | EX-03 へ |
| PRE-UC-009-003 | キャンセルを完了するには、注文の状態が注文受付または支払済である。 | EX-04 へ |

## 7. Postcondition



### 7.1 正常終了

- 注文の状態がキャンセル済で、キャンセル日時に処理時刻（日本時間）が記録されている。
- 注文の全明細の数量が、それぞれの在庫単位の在庫数量へ1回だけ加算されている。
- 注文状態履歴に、変更前状態が注文受付または支払済、変更後状態がキャンセル済、実行した利用者がその購入者（実行者の利用者区分 購入者）の履歴が1件追加されている。
- 支払済注文の場合、支払日時と決済記録（件数・決済結果・決済金額・取引参照番号・処理日時）は変化していない。
- 注文詳細で支払可否・キャンセル可否がともに「不可」となる。


### 7.2 失敗終了

- エラー時は、注文の状態・各日時・在庫数量・注文状態履歴・決済記録は一切変化しない。
- 同じ注文の在庫が2回以上戻されることはない。

## 9. Acceptance Criteria / 合否判定基準



### 9.1 AC-UC-009-001：注文受付の注文をキャンセルすると全明細の数量が在庫へ戻る

| 項目 | 内容 |
|---|---|
| Type | 機能 |
| 関連Requirement ID | FR-034 |
| 関連Flow | MAIN |
| 優先度 | 必須 |

#### Given

- 購入者A（buyer-a@example.com）がログイン済み。
- 注文 PO-00000001：所有者 購入者A、状態 注文受付、明細 MUG-WHT-01（税抜単価2,500円）×2 と PLATE-BLU-02（税抜単価1,850円）×3、小計10,550円、送料0円、消費税額1,055円、合計11,605円、支払日時・キャンセル日時は値なし。
- PO-00000001 の決済記録0件、注文状態履歴1件（なし→注文受付）。
- 在庫単位 MUG-WHT-01 の在庫数量8、PLATE-BLU-02 の在庫数量5。


#### When

- 購入者Aが PO-00000001 のキャンセルを要求する。


#### Then

- キャンセルが完了し、キャンセル後の注文詳細が示される。状態 キャンセル済、キャンセル日時は要求の送信時刻以上・結果の受信時刻以下（秒単位で判定）の日本時間の日時、支払日時は値なし、支払可否・キャンセル可否はともに「不可」。
- 状態履歴は2件で、2件目が変更前状態 注文受付、変更後状態 キャンセル済、実行者の利用者区分 購入者。この履歴の実行した利用者は購入者Aとして記録されている（管理者の注文詳細で確認できる）。
- 在庫単位 MUG-WHT-01 の在庫数量10、PLATE-BLU-02 の在庫数量8。
- 決済記録0件のまま。注文の各金額・明細・配送先は変化しない。
