管理者（EC運営担当）が、非公開商品を含む全在庫単位の在庫数量と低在庫（在庫数量5以下）を、SKU・商品名・仕入先・低在庫の条件で絞り込んで確認し、本システム外で行う補充の判断に使えるようにする。

## 3. 目的・開始条件



### 3.1 Goal

管理者（EC運営担当）が、非公開商品を含む全在庫単位の在庫数量と低在庫（在庫数量5以下）を、SKU・商品名・仕入先・低在庫の条件で絞り込んで確認し、本システム外で行う補充の判断に使えるようにする。


### 3.2 Trigger

管理者が管理者向け共通ヘッダーの「在庫単位一覧」を押す。API を利用する場合は、管理者が在庫単位一覧 API を呼び出す。

## 7. Postcondition



### 7.1 正常終了

- 管理者が、条件を満たす在庫単位の在庫数量・低在庫（is_low_stock）を、SKU昇順・1ページ50件で確認できている。
- 表示される在庫数量は、照会時点までに確定した注文確定（減算）・キャンセル（加算）・初期データ一括投入をすべて反映した値である。
- 照会のみであり、在庫単位・注文は変化していない。


### 7.2 失敗終了

- エラー時も在庫単位・注文は変化しない。
- 購入者・来訪者に仕入先・非公開商品の在庫単位の情報は返らない。

### 9.1 AC-UC-010-001：非公開商品を含む全在庫単位が SKU昇順で表示される

| 項目 | 内容 |
|---|---|
| Type | 機能 |
| 関連Requirement ID | FR-040 |
| 関連Flow | MAIN |
| 優先度 | 必須 |

#### Given

- 管理者X（admin-01@example.com、ロール admin）がログイン済み。
- 在庫単位は標準在庫データの5件のみ（在庫数量 MUG-BLK-01=6、MUG-WHT-01=5、PLATE-BLU-02=0、TOWEL-01=100、XMUG-01=30。XMUG-01 は非公開商品）。注文は0件。

- 管理者Xが条件を指定せずに在庫単位一覧 API を呼び出す。

- MUG-WHT-01 の行は sku=MUG-WHT-01、item_code=ITEM-001、item_name=Steel Mug、variant_name=ホワイト／350ml、item_is_public=true、supplier_id＝SUP-A の仕入先ID、supplier_name=青葉金物、price=2500、quantity=5、is_low_stock=true で、stock_unit_id・item_id を含む。
