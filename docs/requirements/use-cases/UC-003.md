## 1. 本書の目的と適用範囲



### 1.1 目的

来訪者・購入者が、商品分類とキーワードで公開中の商品を探し、並び順・ページを切り替えて一覧を確認し、商品詳細で規格（在庫単位）ごとの税込価格と在庫を確認して、購入する在庫単位を選べる状態にする。


### 1.2 適用範囲

| 区分 | 内容 |
|---|---|
| Use Case ID | UC-003 |
| 対象ユースケース | 商品を探して閲覧する |
| 対象リリース・範囲 | MiniCommerce 初期リリース |
| 本書で定義する | Goal、Actor、Trigger、Precondition、Flow、Postcondition、Business Rule、AC |
| 本書で定義しない | 新たな実装方式の決定。受領済みのAPI・画面条件は要求根拠として維持 |

対象範囲（原資料 In Scope）：

- 商品分類一覧照会（FR-010、GET /api/collections）
- 商品一覧検索（FR-011、GET /api/items）：分類（配下の分類を含む）・キーワードによる絞り込み、並び順（new／price_asc／price_desc／name）、1ページ20件のページング
- 商品詳細照会（FR-012、GET /api/items/{item_id}）：在庫単位ごとの規格名・SKU・税抜価格・税込価格・在庫数量・在庫有無
- 商品一覧画面（SCR-001）・商品詳細画面（SCR-002）での表示（税込価格の主表示と税抜価格の併記）
- 未ログインの来訪者による閲覧。購入者・管理者が認証トークン付きで要求した場合も同じ結果を返すこと
- 来訪者が SCR-002 でカートに入れる操作をした場合のログイン画面（SCR-004）への遷移

対象外（原資料 Out of Scope）：

- カートへの投入・数量変更（UC-004）
- 商品・分類・仕入先・在庫単位の登録・更新・削除（FR-OUT-02。初期データ一括投入 UC-013 で登録する）
- 商品画像、商品レビュー、お気に入り、おすすめ表示（FR-OUT-13）
- 管理者向けの在庫単位一覧（非公開商品・仕入先を含む照会。UC-010）
- スマートフォン専用画面（FR-OUT-14）

## 3. 目的・開始条件



### 3.1 Goal

来訪者・購入者が、商品分類とキーワードで公開中の商品を探し、並び順・ページを切り替えて一覧を確認し、商品詳細で規格（在庫単位）ごとの税込価格と在庫を確認して、購入する在庫単位を選べる状態にする。


### 3.2 Trigger

来訪者または購入者が商品一覧画面（SCR-001。トップ画面）を表示したとき、共通ヘッダーのキーワード検索欄で検索したとき、または一覧から商品を選択したとき。Web API では GET /api/collections、GET /api/items、GET /api/items/{item_id} の要求を受け付けたとき。


### 3.3 Precondition

| ID | 前提条件 | 満たさない場合の扱い |
|---|---|---|
| PRE-UC-003-001 | 商品分類・商品・在庫単位が初期データ一括投入（UC-013）で登録されている（0件の場合は ALT-05 のとおり空の結果を返す）。 | 原資料では前提ごとの個別対応は未記載。機能要件と6章の例外フローを参照 |
| PRE-UC-003-002 | 商品の閲覧は認証を必要としない。ログインしていない来訪者が実行でき、購入者・管理者がログイン中に実行した場合も受け付ける。 | 原資料では前提ごとの個別対応は未記載。機能要件と6章の例外フローを参照 |
| PRE-UC-003-003 | MiniCommerce が稼働している（計画停止中でない）。 | 原資料では前提ごとの個別対応は未記載。機能要件と6章の例外フローを参照 |

## 7. Postcondition



### 7.1 正常終了

- 来訪者・購入者は、公開状態が「公開」かつ在庫単位を1件以上持つ商品だけを、指定した分類（配下を含む）・キーワード・並び順・ページで確認できている。
- 商品詳細で、在庫単位ごとの規格名・SKU・税抜価格・税込価格・在庫数量・在庫有無を SKU 昇順で確認できている。仕入先の情報は表示・応答に含まれていない。
- 閲覧操作によって商品・分類・在庫単位・カートのデータは変化していない。


### 7.2 失敗終了

- 入力不備・対象なし・システムエラーのいずれの場合も、データは変化しない。
- 非公開商品・在庫単位を持たない商品の名称・説明・価格は応答・画面に表示されない。
- エラー応答は error.code・error.message・error.details・error.context の形式で返され（context は該当なしの場合は空オブジェクト）、スタックトレース・SQL 文を含まない。
