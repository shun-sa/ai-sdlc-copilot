## 1. 本書の目的と適用範囲

### 1.1 目的

来訪者・購入者が、商品分類とキーワードで公開中の商品を探し、並び順・ページを切り替えて一覧を確認し、商品詳細で規格（在庫単位）ごとの税込価格と在庫を確認して、購入する在庫単位を選べる状態にする。

### 1.2 適用範囲

| 区分 | 内容 |
|---|---|
| Use Case ID | UC-003 |
| 対象ユースケース | 商品を探して閲覧する |
| 対象リリース・範囲 | MiniCommerce 初期リリース |
| 本書で定義する | Goal、Actor、Trigger、Precondition、Main/Alternative/Exception Flow、Postcondition、Business Rule、Acceptance Criteria |
| 本書で定義しない | 実装方式、画面デザイン詳細、物理データ構造、API・ファイルの物理仕様 |

対象範囲：

- 商品分類一覧照会（FR-010）
- 商品一覧検索（FR-011）：分類（配下の分類を含む）・キーワードによる絞り込み、並び順（新着順／価格の安い順／価格の高い順／商品名順）、1ページ20件の一覧の分割表示
- 商品詳細照会（FR-012）：在庫単位ごとの規格名・SKU・税抜価格・税込価格・在庫数量・在庫有無
- 上記3機能の画面と Web API による提供
- 商品一覧画面（SCR-001）・商品詳細画面（SCR-002）での表示（税込価格の主表示と税抜価格の併記）
- 未ログインの来訪者による閲覧。購入者・管理者がログイン状態で要求した場合も同じ結果を返すこと
- 来訪者が SCR-002 でカートに入れる操作をした場合のログイン画面（SCR-004）への遷移

対象外：

- カートへの投入・数量変更（UC-004）
- 商品・分類・仕入先・在庫単位の登録・更新・削除（FR-OUT-02。初期データ一括投入 UC-013 で登録する）
- 商品画像、商品レビュー、お気に入り、おすすめ表示（FR-OUT-13）
- 管理者向けの在庫単位一覧（非公開商品・仕入先を含む照会。UC-010）
- スマートフォン専用画面（FR-OUT-14）

## 3. 目的・開始条件

### 3.1 Goal

来訪者・購入者が、商品分類とキーワードで公開中の商品を探し、並び順・ページを切り替えて一覧を確認し、商品詳細で規格（在庫単位）ごとの税込価格と在庫を確認して、購入する在庫単位を選べる状態にする。

### 3.2 Trigger

来訪者または購入者が商品一覧画面（SCR-001。トップ画面）を表示したとき、キーワードで検索したとき、または一覧から商品を選択したとき。または Web API で商品分類一覧照会・商品一覧検索・商品詳細照会を要求したとき。

### 3.3 Precondition

| ID | 前提条件 | 満たさない場合の扱い |
|---|---|---|
| PRE-UC-003-001 | 商品分類・商品・在庫単位が初期データ一括投入（UC-013）で登録されている（0件の場合は ALT-05 のとおり空の結果を返す）。 | 該当なし（0件の場合も開始でき、ALT-05 となる） |
| PRE-UC-003-002 | 商品の閲覧は認証を必要としない。ログインしていない来訪者が実行でき、購入者・管理者がログイン中に実行した場合も受け付ける。 | 該当なし（ログイン状態にかかわらず開始できる。ログイン中の場合は ALT-06） |
| PRE-UC-003-003 | MiniCommerce が稼働している（計画停止中でない）。 | 開始不可。処理中に障害が発生した場合は EX-03 |

## 4. 基本フロー

| Step | Actor / System | 操作・振る舞い | 結果・状態 |
|---|---|---|---|
| 1 | ACT-001 来訪者 / ACT-002 購入者 | 商品一覧画面（SCR-001）を表示する | 一覧の表示が要求される |
| 2 | System | 商品分類一覧（FR-010）を木構造の深さ優先順で表示し、商品一覧（FR-011。新着順）の1ページ目（最大20件）を表示する。各商品に商品名、最低価格（税込価格を主表示し税抜価格を併記）、在庫の有無を表示する | 公開状態が「公開」かつ在庫単位を1件以上持つ商品だけが表示され、総件数とページ移動の操作（前へ／次へ・ページ番号）が表示される |
| 3 | ACT-001 来訪者 / ACT-002 購入者 | 分類の選択、キーワードによる検索、並び順の選択、ページ移動のいずれかを行う（ALT-01〜ALT-04） | 検索条件が指定される |
| 4 | System | 指定された条件で FR-011 を実行し、結果を SCR-001 に表示する | 指定したすべての条件を満たす（条件を「かつ」で組み合わせた）公開商品だけが表示される |
| 5 | ACT-001 来訪者 / ACT-002 購入者 | 一覧から商品を1件選択する | 詳細の表示が要求される |
| 6 | System | 商品詳細画面（SCR-002）に FR-012 の結果を表示する。商品名、商品説明、所属分類、在庫単位ごと（SKU の昇順）の規格名・SKU・税込価格（税抜価格併記）・在庫数量を表示し、在庫数量0の在庫単位は「在庫切れ」と表示する。仕入先は表示しない | 規格ごとの価格と在庫を確認できる |
| 7 | ACT-001 来訪者 / ACT-002 購入者 | 購入する在庫単位を選ぶ | 購入者はカートへの投入（UC-004）へ進む。来訪者は ALT-07 へ進む |

## 7. Postcondition

### 7.1 正常終了

- 来訪者・購入者は、公開状態が「公開」かつ在庫単位を1件以上持つ商品だけを、指定した分類（配下を含む）・キーワード・並び順・ページで確認できている。
- 商品詳細で、在庫単位ごとの規格名・SKU・税抜価格・税込価格・在庫数量・在庫有無を SKU 昇順で確認できている。仕入先の情報は表示・通知内容に含まれていない。
- 閲覧操作によって商品・分類・在庫単位・カートのデータは変化していない。

### 7.2 失敗終了

- 入力不備・対象なし・システムエラーのいずれの場合も、データは変化しない。
- 非公開商品・在庫単位を持たない商品の名称・説明・価格は通知内容・画面に表示されない。
