## 1. 本書の目的と適用範囲



### 1.1 目的

購入者（ACT-002）が、配布されたクーポンのコードを自分のカートに適用し、有効期間と最低購入金額の条件を満たす場合に割引額・割引後小計・送料・消費税額・合計金額の内訳を確認できるようにする。不要になったクーポンは解除できる。1つのカートに適用できるクーポンは1枚までとし、条件を満たさない場合は適用を受け付けずに理由を示す。


### 1.2 適用範囲

| 区分 | 内容 |
|---|---|
| Use Case ID | UC-005 |
| 対象ユースケース | クーポンを適用・解除する |
| 対象リリース・範囲 | MiniCommerce 初期リリース |
| 本書で定義する | Goal、Actor、Trigger、Precondition、Flow、Postcondition、Business Rule、AC |
| 本書で定義しない | 実装方式、画面デザイン詳細、物理データ構造、API・ファイルの物理仕様 |

対象範囲：

- クーポン適用（FR-024）：コードの正規化（前後空白の除去・英字の大文字化）、形式・カート明細・併用・存在・有効期間・最低購入金額の判定、カートへの適用。
- クーポン解除（FR-025）：適用中のクーポンをカートから外す。未適用の場合は変化なしで正常終了する。
- 注文金額計算（FR-026）：割引額（定額・定率）を含む金額内訳の再計算と、適用中クーポンの条件の再判定結果（適用可否・適用不可理由）の提示。
- 未ログインの利用者・管理者による適用・解除の拒否。

対象外：

- カート明細の追加・数量変更・削除の操作（UC-004）。ただし、それらの操作後に適用中クーポンの判定結果が変わることは本UCで扱う。
- 注文確定時のクーポン条件の再判定（UC-006）。
- クーポンの登録・変更・削除（FR-OUT-02。初期データ一括投入 UC-013 で登録する）。
- 複数クーポンの併用、ポイント、ギフト券、自動適用の割引キャンペーン（FR-OUT-05）。

## 3. 目的・開始条件



### 3.1 Goal

購入者（ACT-002）が、配布されたクーポンのコードを自分のカートに適用し、有効期間と最低購入金額の条件を満たす場合に割引額・割引後小計・送料・消費税額・合計金額の内訳を確認できるようにする。不要になったクーポンは解除できる。1つのカートに適用できるクーポンは1枚までとし、条件を満たさない場合は適用を受け付けずに理由を示す。


### 3.2 Trigger

購入者が SCR-005 カートでクーポンコードを入力して「適用する」を操作したとき、または適用中クーポンの「解除する」を操作したとき。Web API で同等の適用・解除を要求したとき。


### 3.3 Precondition

| ID | 前提条件 | 満たさない場合の扱い |
|---|---|---|
| PRE-UC-005-001 | 購入者がログイン済みで、ログイン状態の有効期間内である。 | 開始不可。未ログインの場合は EX-01（認証エラー）、管理者がログインしている場合は EX-02（権限エラー）とする |
| PRE-UC-005-002 | 適用する場合、購入者の利用中カートに明細が1件以上ある（UC-004）。 | クーポンを適用できない。EX-04（カートが空）とする |
| PRE-UC-005-003 | クーポン（コード、表示名、割引方式、割引値、最低購入金額、有効開始日時、有効終了日時）は初期データ一括投入（FR-060）で登録済みである。 | 入力したコードのクーポンが登録されていない場合は EX-06（該当するクーポンが無い）とする |


## 4. 基本フロー

| Step | Actor / System | 操作・振る舞い | 結果・状態 |
|---|---|---|---|
| 1 | 購入者 | SCR-005 カートでクーポンコードを入力し、「適用する」を操作する（FR-024） | クーポン適用の要求が送信される |
| 2 | System | ログイン状態・権限を判定し、コードの前後空白を除去して英字を大文字に正規化したうえで、正規化後のコードが1〜20文字の英大文字・数字・ハイフンであることを判定する（FR-024） | 正規化後のコードで判定を続ける |
| 3 | System | カート明細が1件以上あること、クーポンが未適用であること、正規化後のコードに一致するクーポンが存在すること、現在日時が有効開始日時以上かつ有効終了日時以下であること、小計が最低購入金額以上であることを、この順に判定する（FR-024） | 判定をすべて満たす |
| 4 | System | カートにクーポンを適用し、割引額・割引後小計・送料・消費税額・合計を再計算する（FR-026）。更新後のカート内容を示す。適用中のクーポンについて、クーポンコード・表示名・割引方式・割引値・最低購入金額・有効開始日時・有効終了日時と、適用可否「可」を示す | カートに適用中のクーポンが1枚ある |
| 5 | System | SCR-005 を再表示し、完了メッセージと、適用中クーポンのコード・表示名・割引内容と金額内訳（小計・割引額・割引後小計・送料・消費税額・合計（税込））を表示する | 購入者が割引後の金額を確認できる |
| 6 | 購入者 | 金額内訳を確認し、「注文手続きへ進む」を操作して UC-006 へ進む | 本UCは終了する。クーポンはカートに適用されたまま |

## 7. Postcondition



### 7.1 正常終了

- 適用の場合：カートに適用中のクーポンが1枚だけあり、示される金額内訳は FR-026 の規則で算出された割引後の値である。
- 解除の場合：カートのクーポンは未適用で、割引額は0円である。
- カート明細と在庫単位の在庫数量は、適用・解除の前後で変化しない。


### 7.2 失敗終了

- エラー（入力エラー・認証エラー・権限エラー・業務エラー・システムエラー）となった場合、カートのクーポンの適用状態・金額内訳・明細は操作前の状態のまま。
- 他の購入者のカートは参照も変更もされない。
