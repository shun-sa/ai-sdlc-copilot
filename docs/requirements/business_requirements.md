## 1. 本書の目的と適用範囲

### 1.1 目的

本書は、株式会社あおば雑貨（以下「当社」）が初の自社ECサイトとして立ち上げる MiniCommerce について、業務として達成する目的、対象業務の範囲、業務ルール、関係者の要求、業務量を定義し、関係者間で合意するための文書である。読み手は、承認者であるEC事業責任者（取締役）と、EC運営担当（EC事業部）・出荷担当（物流課）・システム運用担当（情報システム課）、および MiniCommerce の要件定義・設計・開発・テストの担当者とする。

### 1.2 適用範囲

| 項目 | 内容 |
|---|---|
| 対象システム | MiniCommerce（当社初の自社ECサイト）。会員向けにWEBでの注文（商品閲覧→カート→クーポン適用→注文確定→支払→出荷→配達完了）を提供する。リリース範囲は初期リリース（第1期） |
| 対象組織 | 株式会社あおば雑貨：EC事業部（EC運営担当）、物流課（出荷担当）、情報システム課（システム運用担当）、EC事業責任者（取締役） |
| 対象業務領域 | 会員向けWEB受注業務（5.1 の BP-01〜BP-10）と、これに接するシステム化対象外の業務（BP-11 入荷・在庫補充、BP-12 返品・返金） |
| 対象フェーズ・期間 | 第1期（要件定義開始 2026-10、稼働開始予定 2027-04-01）。想定運用期間は稼働開始から5年 |

本書では、次の用語を以下の意味で用いる。

- 当社：株式会社あおば雑貨。
- 購入者：会員登録を済ませてログインした利用者（STK-01）。来訪者：ログインしていない閲覧者（STK-02）。
- 受注担当：現行の電話・FAX・メールによる通信販売で注文を受け付け、受注台帳に入力する担当者。EC業務の役割ではなく、本書では現行業務の説明にのみ用いる。
- 管理者：EC運営担当（STK-03）・出荷担当（STK-04）が、本システムで在庫・注文の確認、出荷・配達完了の登録、注文のキャンセルを行う際の立場。管理者は購入（カートへの投入・注文確定・支払）を行わない。
- 商品（Item）：販売する品目。商品分類（Collection）で分類する（1つの商品が複数の商品分類に属することがある）。
- 在庫単位（StockUnit）：商品の規格（色・サイズ）ごとの販売単位。SKU（在庫単位を識別するコード）で識別し、税抜価格と在庫数量を持つ。1つの商品は1つ以上の在庫単位を持つ。
- 在庫数量：在庫単位ごとの、ECで販売できる数量。実店舗の在庫とは分けて管理する（BCN-04）。
- 低在庫：在庫数量が5個以下の状態。
- 仕入先（Supplier）：在庫単位の仕入元の事業者。
- カート（Cart）：購入者が注文確定前に、購入予定の在庫単位と数量をまとめたもの。
- 明細：カートまたは注文における在庫単位ごとの行。同一の在庫単位は1つの明細にまとめる。
- クーポン（Coupon）：購入者がコードを入力して適用する割引。割引方式（定額／定率）、割引値、最低購入金額、有効期間（有効開始日時〜有効終了日時）を持つ。
- 注文（PurchaseOrder）：購入者が確定した購入の申込み。確定時に注文番号を発行する。
- 注文状態：注文受付／支払済／出荷済／配達完了／キャンセル済 の5つ。
- 小計：各明細の税抜単価×数量の合計（税抜・割引前）。
- 割引額・割引後小計・送料・消費税額・合計金額：7.2 の算出方法による金額。金額はすべて整数の円とする。
- 模擬決済：本リリースで決済代行サービスの代わりに用いる、本システム内で承認または否認を返す代替の仕組み。実在の決済サービスには接続しない。
- 一括投入：EC運営担当が作成した定義ファイルの内容を、システム運用担当が本システムにまとめて登録すること。
- 営業日：土曜日・日曜日・祝日を除く日。
- 日時：日本時間（JST）で表す。

## 2. 背景

### 2.1 業務環境

- 当社は生活雑貨・キッチン用品の小売事業者であり、実店舗2店舗を運営するとともに、電話・FAX・メールによる通信販売を行っている（出典：当社 EC事業計画（2026年6月策定））。
- 通信販売の受注件数は、2025年度実績で平均40件/日、ピーク120件/日（12月）である（出典：当社 2025年度 通信販売業務実績（社内集計））。
- 通信販売の受付手段は人手による電話・FAXであり、営業時間外（平日18時以降・土日祝）の注文を受け付けていない（出典：当社 2025年度 通信販売業務実績（社内集計））。
- 通信販売では、2025年度の月平均で、在庫切れ後の受注による受注取消が25件、金額・送料・割引の計算誤りによる請求額の訂正が12件、割引券の誤適用が6件、注文状況の電話問い合わせが300件、同一商品の大量注文による人気商品の欠品が5件発生している。受注入力には1件あたり平均8分を要している（出典：当社 2025年度 通信販売業務実績（社内集計））。
- EC事業計画では、EC経由の注文を平均100件/日・ピーク400件/日、会員数を稼働後1年で3,000名・3年で10,000名と見込んでいる（出典：当社 EC事業計画（2026年6月策定））。
- 消費税の標準税率は10%であり、消費者に価格を表示する場合は税込価格による総額表示が義務付けられている（出典：消費税法 第63条）。

### 2.2 現行業務・現行システムの概要

ECによる販売は新規業務であり、現行のEC業務・ECシステムは存在しない。現行の通信販売では、電話・FAX・メールで注文を受け、受注担当が表計算ファイルの「受注台帳」に注文内容を入力している。在庫は表計算ファイルの「在庫管理表」で管理し、1日2回（12:00・17:00）更新しているため、受注の時点の在庫数量は分からない。割引は紙・メールで配布する割引券で行い、受注担当が適用条件（最低購入金額・有効期限・併用の可否）を目視で判定している。金額・送料・割引は受注担当が手計算・電卓計算している。購入者が注文状況を確認する手段はなく、購入者は電話で問い合わせている。

| ID | 現行システム・ツール名 | 用途 | 利用業務 | 本件での扱い |
|---|---|---|---|---|
| CUR-01 | 受注台帳（表計算ファイル） | 通信販売の注文内容・金額・状況の記録 | 通信販売の受注業務 | 置換（EC経由の注文の記録を本システムへ置き換える） |
| CUR-02 | 在庫管理表（表計算ファイル） | 商品ごとの在庫数量の管理（1日2回 12:00・17:00 更新） | 在庫管理、入荷・在庫補充（BP-11） | 継続（入荷・在庫補充の管理に継続利用する。稼働開始時のEC在庫の数量は一括投入で登録する。稼働後の補充分の反映方法は BOQ-07 で決定する） |
| CUR-03 | 割引券（紙・メール配布） | 通信販売の購入者への割引の提供 | 通信販売の受注業務 | 置換（クーポンへ置き換える） |
| CUR-04 | 電話・FAX受注 | 通信販売の注文の受付 | 通信販売の受注業務 | 継続（通信販売は当面ECと併存する） |

| 入力となる情報 | カート内の同一在庫単位の既存の数量、カート投入で追加する数量または数量変更後の数量、注文確定時は各明細の数量 |

| 端数処理・境界値 | 数量は1以上の整数。10個ちょうどは受け付ける（10個以下を含む）。11個以上は受け付けない。在庫単位ごとに数え、同一商品で規格が異なる在庫単位は合算しない |
| 結果 | 受け付ける／受け付けない（受け付けない場合、カートの数量は操作前のままとする） |

| 条件：操作 | 条件：操作後の同一在庫単位の数量 | 結果 |
|---|---|---|
| カート投入 | 10個以下 | 受け付ける |
| カート投入 | 11個以上 | 受け付けない（数量は操作前のまま） |
| 数量変更 | 10個以下 | 受け付ける |
| 数量変更 | 11個以上 | 受け付けない（数量は操作前のまま） |
| 注文確定 | 全明細が10個以下 | 数量上限を満たす（BR-18 の他の判定へ進む） |
| 注文確定 | 1明細でも11個以上 | 注文を確定しない |

数値例：カートに同一在庫単位が8個ある場合、2個の追加は受け付ける（10個）、3個の追加は受け付けない（8個のまま）。カートにない在庫単位を11個で投入する操作は受け付けない。10個の明細を11個に変更する操作は受け付けない（10個のまま）。

#### 7.2.2 BR-04：クーポンの有効期間

| 項目 | 内容 |
|---|---|
| 入力となる情報 | 判定時刻（クーポン適用時・カートの金額算出時・注文確定時の日本時間）、クーポンの有効開始日時、有効終了日時 |
| 計算式・判定方法 | 有効開始日時 ≦ 判定時刻 かつ 判定時刻 ≦ 有効終了日時 の場合に有効とする |
| 端数処理・境界値 | 両端を含む。判定時刻が有効開始日時ちょうど、または有効終了日時ちょうどの場合は有効とする。有効開始日時より前は「有効期間前」、有効終了日時より後は「有効期間終了」として適用しない |
| 結果 | 適用できる／適用しない（有効期間前）／適用しない（有効期間終了）。カートに適用済みのクーポンが判定時刻に有効期間外となった場合は割引額を0円とし（BR-06）、クーポンは自動では外さない。注文確定時に有効期間外の場合は注文を確定しない（BR-18） |

| 条件：判定時刻と有効開始日時の関係 | 条件：判定時刻と有効終了日時の関係 | 結果 |
|---|---|---|
| 有効開始日時より前 | 問わない | 適用しない（有効期間前） |
| 有効開始日時以上 | 有効終了日時以下 | 適用できる |
| 有効開始日時以上 | 有効終了日時より後 | 適用しない（有効期間終了） |

数値例：有効期間が 2027-04-01 00:00:00〜2027-04-30 23:59:59 のクーポンは、2027-04-01 00:00:00 と 2027-04-30 23:59:59 には適用でき、2027-03-31 23:59:59（有効期間前）と 2027-05-01 00:00:00（有効期間終了）には適用しない。

#### 7.2.3 BR-06：割引額の算出

| 項目 | 内容 |
|---|---|
| 入力となる情報 | 小計（税抜・割引前）、適用中のクーポンの割引方式（定額／定率）・割引値（定額は円、定率は%）、クーポンの適用条件（BR-03・BR-04）の判定結果 |
| 計算式・判定方法 | 定額：割引額＝min(割引値, 小計)。定率：割引額＝小計×割引率÷100。割引後小計＝小計−割引額 |
| 端数処理・境界値 | 定率の割引額は1円未満切り捨て。定額の割引値が小計を超える場合は割引額＝小計とし、割引後小計は0円とする（0円未満にしない）。割引値が小計と同じ額の場合も割引後小計は0円とする |
| 結果 | 割引額（整数の円）、割引後小計（整数の円） |

| 条件：割引方式 | 条件：小計と割引値の関係 | 結果 |
|---|---|---|
| クーポン未適用、または BR-03・BR-04 を満たさない | 問わない | 割引額0円（割引後小計＝小計） |
| 定額 | 割引値 ≦ 小計 | 割引額＝割引値 |
| 定額 | 割引値 ＞ 小計 | 割引額＝小計（割引後小計0円） |
| 定率 | 問わない | 割引額＝小計×割引率÷100 の1円未満切り捨て |

数値例：小計5,550円・定率10% → 割引額555円。小計1,999円・定率15% → 1,999×15÷100＝299.85 を切り捨てて割引額299円。小計6,000円・定額1,000円 → 割引額1,000円。小計800円・定額1,000円（最低購入金額0円） → 割引額800円（割引後小計0円）。

#### 7.2.4 BR-07：送料

| 項目 | 内容 |
|---|---|
| 入力となる情報 | 割引後小計、カート（注文）に含まれる商品の有無 |
| 計算式・判定方法 | 割引後小計 ≧ 5,000円 の場合は送料0円、割引後小計 ＜ 5,000円 の場合は送料500円 |
| 端数処理・境界値 | 5,000円ちょうどは送料0円（以上を含む）。4,999円は送料500円。判定には割引前の小計ではなく割引後小計を用いる。配送先の地域で送料を変えない（全国一律）。カートに商品が1点もない場合は送料0円 |
| 結果 | 送料（0円または500円） |

| 条件：商品の有無 | 条件：割引後小計 | 結果 |
|---|---|---|
| 1点以上ある | 5,000円以上 | 送料0円 |
| 1点以上ある | 5,000円未満（0円を含む） | 送料500円 |
| 1点もない | 問わない（0円） | 送料0円（小計から合計金額まですべて0円） |

数値例：小計5,550円に定率10%のクーポンを適用すると割引後小計は4,995円となり、割引前の小計が5,000円以上でも送料は500円とする。小計6,000円に定額1,000円のクーポンを適用すると割引後小計は5,000円となり、送料は0円とする。
